# Facial Emotion Recognition with ResNet (FER2025)

Six-class facial emotion recognition from grayscale face images, using a ResNet34 fine-tuned from ImageNet weights, with a real-time webcam demo.

- **Classes:** `angry`, `disgust`, `fear`, `happy`, `sad`, `surprise` (the `neutral` class is excluded)
- **Input:** grayscale, 128 x 128
- **Model:** ResNet34 (torchvision), 1-channel input, custom classification head
- **Framework:** PyTorch

## Dataset

FER2025 from Hugging Face (`imadhavan/FER2025`, with `linkyle910125/FER2025` as a fallback). The dataset is distributed as one `.tar` archive per class. Images are 75 x 75 pixels, stored as a mix of grayscale and RGB files. Up to 10,000 images per class are extracted (`MAX_PER_CLASS`), and the `neutral` class is skipped.

## Preprocessing

The preprocessing is the core of the pipeline. Every step is applied in the order below, and the exact same chain is reproduced at inference time in the webcam script.

### 1. Extraction

- Image files (`.jpg`, `.jpeg`, `.png`) are read from each class archive and written to `data/fer2025_images/<class>/` with sequential names (`0000000.ext`, ...).
- Extraction stops at `MAX_PER_CLASS` images per class.
- Each archive is deleted after extraction to save disk space.

### 2. Reading and integrity check

Every image is opened with PIL. For each file the pipeline records its path, class, width, height, mode, and pixel statistics (mean, standard deviation, min, max) in `data/images_info.csv`. Files that cannot be opened are reported and skipped.

### 3. Cleaning

Five filters are applied in this order, each logged with the number of removed images (per step and per class):

| # | Filter | Rule |
|---|---|---|
| 1 | Too small | width < 32 or height < 32 |
| 2 | Near uniform | pixel standard deviation < 5 |
| 3 | Conflicting labels | the same perceptual hash (pHash, computed on the grayscale image) appears under more than one class: all copies are removed |
| 4 | Exact duplicates | identical MD5 hash: first copy kept |
| 5 | Near duplicates | identical pHash: first copy kept |

Conflicting labels are removed before deduplication on purpose: an image present in two classes is dropped entirely instead of being kept once under an arbitrary label. The cleaned list is saved to `data/clean.csv`.

### 4. Standardization

For each cleaned image:

1. Load as **grayscale** (`cv2.IMREAD_GRAYSCALE`), which also converts the RGB files.
2. **Resize to 128 x 128** with `cv2.INTER_AREA`.
3. Apply **CLAHE** (Contrast Limited Adaptive Histogram Equalization): `clipLimit=2.0`, `tileGridSize=(8, 8)`. This equalizes contrast locally and reduces the effect of lighting differences.
4. Save as PNG in `data/std/<class>/`.

No face cropping is performed in the training pipeline: the dataset images are already faces.

### 5. Train / validation / test split

- Stratified by class, **70% / 15% / 15%**.
- Done with two successive `train_test_split` calls (70/30, then the 30% split in half), `random_state=7`.
- The split is done **after** cleaning and deduplication, so duplicates cannot leak across sets.
- Split files are saved in `data/splits_final/`.

### 6. Normalization

1. Divide pixel values by 255 to get values in [0, 1].
2. Compute a single scalar **mean** and **standard deviation** on the **training set only**.
3. Standardize train, validation and test with those same values: `x = (x / 255 - mean) / std`.

Arrays have shape `(N, 128, 128, 1)`, are stored as float16 in `data/arrays/`, and are converted to float32 tensors of shape `(N, 1, 128, 128)` for PyTorch. The statistics, image size, CLAHE flag and class list are saved in `data/norm_stats.json`.

### 7. Data augmentation (training set only)

Applied on the fly on the normalized tensors:

| Augmentation | Parameters |
|---|---|
| Random horizontal flip | p = 0.5 |
| Random affine | rotation ±15°, translation up to 10% in x and y, scale 0.85 to 1.15 |
| Random erasing | p = 0.25, erased area 2% to 15% of the image |
| Brightness / contrast jitter | `x * (1 + 0.2·u1) + 0.2·u2`, with `u1, u2` drawn uniformly in [-1, 1] |
| MixUp (in the training loop) | alpha = 0.4, applied to 50% of the batches |

Validation and test data are never augmented.

### 8. Reproducibility

- Global seed `7` for Python, NumPy, PyTorch and CUDA.
- `cudnn.deterministic = True`, `cudnn.benchmark = False`, `torch.use_deterministic_algorithms(True, warn_only=True)`, `CUBLAS_WORKSPACE_CONFIG=:4096:8`.
- Seeded DataLoader workers and a seeded shuffle generator.
- Global average pooling is implemented as a plain mean (see below) because the adaptive pooling operator is not deterministic on GPU.

### 9. Inference preprocessing (webcam)

The webcam script reproduces the training chain, plus the steps needed for live video:

1. Mirror the frame and convert it to grayscale.
2. **Detect faces** with OpenCV's Haar cascade (`haarcascade_frontalface_default.xml`, `scaleFactor=1.1`, `minNeighbors=5`, `minSize=(80, 80)`) and keep the largest face.
3. Take a **square crop** around the face with a 10% margin, clamped to the image.
4. Resize the crop to **75 x 75** then to **128 x 128** (both `INTER_AREA`). Going through 75 x 75 first gives webcam faces the same blur as the upscaled training images.
5. Apply the same **CLAHE** and the same **normalization** with the training mean and standard deviation.
6. Run the model, apply a softmax, and smooth the probabilities over time: `smooth = 0.6 * smooth + 0.4 * p`.
7. Display `uncertain` when the highest probability is below 0.40, since the model has no `neutral` class.

## Model architecture

The model is a **ResNet34** from torchvision (`models.get_model("resnet34", weights="DEFAULT")`, ImageNet weights) with the following modifications. All layers are fine-tuned (nothing is frozen).

### Modifications to the standard ResNet34

| Part | Change | Reason |
|---|---|---|
| `conv1` | `Conv2d(1, 64, kernel_size=7, stride=2, padding=3, bias=False)`; the pretrained weights are the **sum of the three RGB filters** | the input is grayscale (1 channel) and the sum keeps the pretrained response to intensity |
| `maxpool` | kept (`USE_MAXPOOL = True`); it can be replaced by `Identity` to keep larger feature maps at a higher compute cost | speed |
| `avgpool` | replaced by `GlobalMean`: `x.mean(dim=(2, 3), keepdim=True)` | same result as `AdaptiveAvgPool2d(1)`, but deterministic on GPU |
| `fc` | replaced by `Dropout(p=0.4)` → `Linear(512, 6)` | new head for 6 classes |

### Feature map sizes (128 x 128 input)

| Stage | Blocks | Channels | Output size |
|---|---|---|---|
| Input | | 1 | 128 x 128 |
| `conv1` (7x7, stride 2) + BatchNorm + ReLU | | 64 | 64 x 64 |
| `maxpool` (3x3, stride 2) | | 64 | 32 x 32 |
| `layer1` | 3 | 64 | 32 x 32 |
| `layer2` | 4 | 128 | 16 x 16 |
| `layer3` | 6 | 256 | 8 x 8 |
| `layer4` | 3 | 512 | 4 x 4 |
| Global mean | | 512 | 1 x 1 |
| Dropout (0.4) + Linear | | 6 | logits |

Each block is a ResNet `BasicBlock`: two 3x3 convolutions, each followed by BatchNorm, with ReLU, plus a skip connection (a 1x1 strided convolution on the shortcut when the shape changes). The model has about 21.3 million parameters.

### Training configuration

| Setting | Value |
|---|---|
| Loss | cross-entropy, no label smoothing |
| Optimizer | AdamW, learning rate `1e-3`, weight decay `5e-2` |
| Schedule | cosine annealing over 100 epochs (`T_max = 100`) |
| Epochs | up to 100, with early stopping |
| Early stopping | patience of 7 epochs on the validation loss; the best checkpoint is kept |
| Batch size | 128 |
| Precision | mixed precision (fp16 autocast + `GradScaler`) on GPU |
| Regularization | dropout 0.4, weight decay, MixUp, augmentation |
| Evaluation | best checkpoint on the test set, with optional test-time augmentation (average of an image and its horizontal mirror, off by default) |

## Usage

### 1. Train (Kaggle)

1. Upload `emotion-project-resnet.ipynb` to Kaggle.
2. In *Settings*, set the accelerator to **GPU** and **Internet** to ON (needed to download the dataset and the pretrained weights).
3. Run all cells. The last cell creates `emotion_webcam.zip` in `/kaggle/working`.
4. Save the notebook with *Save Version > Save & Run All*, then download the zip from the *Output* tab.

### 2. Run the webcam demo (local)

1. Unzip `emotion_webcam.zip`. You get `best_resnet.pt`, `webcam_config.json` and `webcam.py`.
2. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. From that folder, run:
   ```bash
   python webcam.py              # default camera
   python webcam.py --camera 1   # another camera index
   ```
4. Press `q` in the video window to quit (or `Ctrl+C` in the terminal).

The script tries several camera backends and indexes, and prints a clear message if no camera can be opened (camera in use by another app, missing permission).

## Notes

- **OpenCV version:** use `opencv-python` 4.x (not `opencv-python-headless`, and not 5.x). The headless build cannot display the window, and the 5.x package does not provide `cv2.CascadeClassifier`, which is used for face detection.
- **No `neutral` class:** the model always has to choose one of six emotions, which is why low-confidence predictions are displayed as `uncertain`.
- **Face detection:** the Haar cascade works best with frontal, well-lit faces.
- **Model weights:** `best_resnet.pt` is about 80 MB. Do not commit it to Git; share it with GitHub Releases or Git LFS.
